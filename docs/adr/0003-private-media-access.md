# 私有图片内容每次读取均受资源授权约束

状态：已接受（2026-10-21，用户确认 Q14、Q15）。

授权覆盖个人、团队及 Agent 的原图、缩略图、预览、下载和附件内容，而不只覆盖返回图片信息的 API。私有内容的每次新请求都必须经过鉴权，成员被移除或降权后立即拒绝后续不再被允许的请求；已下载至用户设备的副本不在可追回范围内。

存量直链必须纳入迁移和失效验证。仅增加元数据接口授权，或仅给直链设置尚未到期的访问期限，不能单独满足立即撤权的约定。公开图库的已审核公开内容仍按匿名公开访问规则处理。

这一选择增加内容访问链路的授权成本，但使资源权限在 API、浏览器和实际存储内容之间保持一致，防止用户通过旧地址或衍生文件绕过权限撤销。
