# 区分团队协作权限与平台管理权限

状态：已接受（2026-10-21，用户确认 Q2、Q3）。

安全整改保留团队空间的共享协作语义：团队编辑者可编辑和删除其他成员上传的团队图片，授权依据是当前团队成员资格和角色；成员被移除或降权后，相应权限立即撤销。不能把所有资源统一改成仅上传者可操作，否则会破坏团队协作。

平台管理员保留明确的平台管理和图片审核职责，但平台身份不自动授予私人 Agent 会话或个人 MCP 工具的访问权。平台管理权限、团队成员权限和私人资源归属分别判定；存储密钥不返回浏览器。

用户在 Q15 进一步确认：平台管理员默认不能读取个人、团队空间的私人图片内容；后台仅展示管理所需元数据，查看内容需资源方授权，违规处置使用独立、受限并记录理由的管理操作。不能保留通过管理端原始实体或存储地址绕过这一边界的入口。

用户在 Q18 确认授权主体和处置语义：个人资源由所有者授权，团队资源由团队管理员授权；查看权限限定指定资源、限时只读且可随时撤销。违规处置默认隔离而非物理删除，并保留恢复能力和独立审计。

这一边界在保留现有协作及管理能力的同时限制私人资源访问。后续具体接口和测试必须分别验证团队角色、平台管理职责和私人资源归属，不能用单一的全局管理员判断替代。
