# VisionSpace 微信小程序

原生小程序 + TypeScript。当前为 **M5：私有图片鉴权下载**，包含：

- 发现 tab：热门 / 最新 / 精选 / 随机榜单、关键词搜索、分类筛选
- 作品详情：大图预览、作者与元信息、只读计数、公开作品分享
- 微信登录：`wx.login` 静默登录；未绑定微信时用账号密码一次性绑定（`/user/wx/bind`）
- 空间 tab：个人 + 团队空间列表（含角色），首次使用自动创建个人空间
- 空间详情：图片网格（隔离作品显示占位）、色卡按颜色检索、从相册图片取色检索
- 私有图片鉴权下载：`wx.downloadFile` 带令牌头下载到本地再展示，令牌不进 URL；
  下载队列限流去重，已下载的图翻页回来不重复下载；只给本站地址发令牌，
  缓存上限 60 条、5 分钟过期、按账号隔离（换账号立即失效）
- 空间上传（所有者 / 管理员 / 可编辑可见）：一次最多 9 张，逐张改名称，
  超 2MB 自动压缩，串行上传，失败可单独重试；上传后回到空间自动刷新
- 匿名行为上报（曝光 / 点击 / 浏览），来源标记为 `MINI_PROGRAM(4)`，仅公开作品
- 跟随系统主题：深色极光 / 浅色紫漾

## 本地开发

1. 安装依赖（只用于类型定义与单测；小程序代码由开发者工具的 TypeScript 编译插件处理）：

   ```bash
   cd miniprogram
   npm install
   ```

2. 用微信开发者工具「导入项目」，目录选 `miniprogram/`，把 `project.config.json`
   里的 `appid` 换成自己的 AppID（`touristappid` 仅游客模式）。

3. 请求域名：
   - 默认直连 `https://visionspace.space`（已 ICP 备案，体验版同样要求备案域名）。
   - 想连本地后端时，在开发者工具控制台执行
     `wx.setStorageSync('vs_api_base', 'http://127.0.0.1:8081')`，并在「详情 →
     本地设置」勾选「不校验合法域名」。清除该存储项即恢复默认。

4. 合法域名配置（开发管理 → 开发设置 → 服务器域名）：把
   `https://visionspace.space` 加到 **request** 与 **downloadFile** 两个合法域名。
   公开图库的 `<image>` 走 request 域名，私有图片走 downloadFile 域名，缺一不可。

## 约定

- **id 一律用字符串**：后端 `JsonConfig` 把 Long 序列化成十进制字符串，图片/空间/用户
  id 是 19 位雪花值，转成 number 会被舍入成另一个 id（点击卡片后 404）。number 只用于
  计数、体积、页码。
- **令牌只出现在请求头**：`tokenName` 由登录响应下发，不要写死 `satoken`。
  令牌不放进 URL：查询参数会进 nginx 访问日志、Referer 与图片缓存。
  私有图片用 `wx.downloadFile` 带鉴权头下载到本地再展示。服务端同样只认请求头，
  查询串里的 `satoken` 不会被接受，不要指望它兜底。
- **图片地址只认同源**：`isTrustedContentUrl` 用 `API_BASE_URL` 前缀判断，
  非本站地址直接拒绝下载——否则服务端返回的数据一旦被改成外链，就等于把令牌送给第三方。
- **私有图片缓存会失效**：换账号、超过 5 分钟、收到 401 或 403 时都必须重新鉴权下载；
  缓存的只是本地临时文件路径，不是权限证明。
