# VisionSpace 微信小程序

原生小程序 + TypeScript。当前为 **M4：空间上传**，包含：

- 发现 tab：热门 / 最新 / 精选 / 随机榜单、关键词搜索、分类筛选
- 作品详情：大图预览、作者与元信息、只读计数、公开作品分享
- 微信登录：`wx.login` 静默登录；未绑定微信时用账号密码一次性绑定（`/user/wx/bind`）
- 空间 tab：个人 + 团队空间列表（含角色），首次使用自动创建个人空间
- 空间详情：图片网格（隔离作品显示占位）、色卡按颜色检索、从相册图片取色检索
- 空间上传（所有者 / 管理员 / 可编辑可见）：一次最多 9 张，逐张改名称，
  超 2MB 自动压缩，串行上传，失败可单独重试；上传后回到空间自动刷新
- 匿名行为上报（曝光 / 点击 / 浏览），来源标记为 `MINI_PROGRAM(4)`，仅公开作品
- 跟随系统主题：深色极光 / 浅色紫漾

## 本地开发

1. 安装依赖（只用于类型定义与单测；小程序代码由开发者工具的 TypeScript 编译插件处理）：

   ```bash
   cd miniprogram
   npm install
   ```

2. 用微信开发者工具「导入项目」，目录选 `miniprogram/`，把 `project.config.json`
   里的 `appid` 换成自己的 AppID（`touristappid` 仅游客模式）。

3. 请求域名：
   - 默认直连 `https://visionspace.space`（已 ICP 备案，体验版同样要求备案域名）。
   - 想连本地后端时，在开发者工具控制台执行
     `wx.setStorageSync('vs_api_base', 'http://127.0.0.1:8081')`，并在「详情 →
     本地设置」勾选「不校验合法域名」。清除该存储项即恢复默认。

4. 合法域名配置（开发管理 → 开发设置 → 服务器域名）：把
   `https://visionspace.space` 加到 request 合法域名。图片通过同一域名加载，
   `<image>` 也需要该域名可访问。

## 检查

```bash
npm run type-check   # src 与 tests 两套 tsconfig
npm test             # Vitest，无 DOM 纯逻辑
```

浏览器自动化，UI 走下面的真机清单。

## 真机清单

### M2 公开图库

发现页：

- [ ] 首次进入默认「热门」榜单，卡片双列排布，图片不变形
- [ ] 依次切换 最新 / 精选 / 随机：列表重置、无重复条目
- [ ] 上拉加载更多：分页无重复；到底显示「没有更多了」
- [ ] 关键词搜索：回车触发，结果来自检索接口；清空关键词回到当前榜单
- [ ] 分类筛选：点分类立即刷新；切榜单会清空关键词与分类
- [ ] 下拉刷新：回到当前榜单/筛选条件的第一页
- [ ] 断网或后端 5xx：显示错误文案与「重新加载」，恢复后重试成功
- [ ] 图片无内容入口（isolated / 无文件）时显示占位，不出现破图

详情页：

- [ ] 大图按宽度铺满，点击进入系统预览并可缩放
- [ ] 标题、作者、分类、日期、文件体积展示正确
- [ ] 计数（浏览/点赞/收藏/分享）只读展示，无点赞按钮
- [ ] 公开作品出现「分享给朋友」，转发卡片打开后仍能看到该作品
- [ ] 非公开作品（构造 `spaceId` 数据）不出现分享入口，匿名打开给出无权限提示

### M3 登录与空间

- [ ] 首次进入「空间」：未登录引导页；点「微信登录」后提示绑定账号密码
- [ ] 绑定：错误密码给出后端文案、不写入登录态；正确账号一次绑定后再次进入静默登录
- [ ] 首次登录后自动创建个人空间（`<昵称>的空间`），重复进入不重复创建
- [ ] 空间列表展示个人与团队空间、角色（创建者/管理员/可编辑/只读）
- [ ] 进入空间：网格加载、上拉分页、下拉刷新；隔离作品显示「内容已隔离」占位
- [ ] 空间图片大图与预览可打开（内容接口用查询参数带令牌）
- [ ] 点色卡：展示相近颜色前 12 张，可清除筛选回到全部作品
- [ ] 「从图片取色」：选相册图片后自动检索；取色失败时有提示且可改用色卡
- [ ] 非空间成员打开空间：给出无权限提示，不出现破图或空列表误导
- [ ] 「我的」：显示本地昵称与 ID；退出登录后空间 tab 回到未登录引导
- [ ] 空间作品详情不出现分享入口；公开作品仍可分享

### M4 空间上传

- [ ] 空间详情仅所有者 / 管理员 / 可编辑看到「上传作品」；只读成员看不到
- [ ] 选图：一次最多 9 张，超出时提示；相册与拍照都能选
- [ ] 大图（>2MB）自动压缩后上传成功；压缩仍超限时给出「请换一张」提示
- [ ] 名称可逐张修改，清空名称回退到默认名；超长名称被截断
- [ ] 上传中按钮禁用、显示进度；串行上传，顺序与列表一致
- [ ] 单张失败（断网 / 无权限 / 配额不足）只标红该张，其余继续；可点重试
- [ ] 上传成功提示「待审核」，返回空间后列表自动刷新并出现新作品
- [ ] 令牌失效时提示重新登录，不会把整个队列静默丢掉
- [ ] 上传量超每日次数或存储额度时展示服务端文案（非笼统「操作失败」）

### 主题与埋点

- [ ] 系统切深色：导航栏、tabBar、页面背景、卡片、文字全部跟随极光配色
- [ ] 系统切浅色：恢复紫漾配色，无残留深色块
- [ ] 后端 `picture_action` 中出现 `source=4` 的公开作品曝光/点击/浏览记录
- [ ] 同一张图在一次页面停留中不重复上报曝光；空间作品不产生上报

## 目录

```
src/
  app.ts / app.json / app.wxss / theme.json / sitemap.json
  config/env.ts            API 域名、版本号
  services/                请求层、内容地址、登录/空间/颜色检索、上传与压缩、登录态存储
  logic/                   feed（分页状态机）、gallery（展示）、color（颜色）、
                           spaces（空间合并）、upload（上传队列规则）、auth（账号校验）、
                           telemetry、errors、url、long
  components/picture-card/ 作品卡片
  pages/discover          公开图库
  pages/space             空间列表（个人/团队）
  pages/space-detail      空间网格 + 颜色检索
  pages/upload            空间上传队列
  pages/picture           作品详情
  pages/login             微信登录 / 账号绑定
  pages/me                资料与退出登录
tests/                     Vitest
```

`logic/` 与 `services/` 不依赖页面生命周期，纯逻辑改动应同时补 `tests/`。
