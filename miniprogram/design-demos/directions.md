## Phase 3 · 规格（三版共用，只写「要说什么」）

**产品**：VisionSpace，一个图片分享 / 智能图库平台。Web 端已有体系（紫漾 / 极光双主题），
小程序是同一个账号体系的移动端：发现公开图库、进自己的空间看图与上传。

**受众与场景**：摄影爱好者与轻量创作者。多在手机上刷图、存图、给自己的空间补图；
进入方式以「朋友转发的一张图」和「自己再进来看」为主，单次使用以几十秒计。

**必须出现的真实内容**（三版一致，只换设计）：

| 页面 | 内容 |
|---|---|
| 发现 | 榜单（热门 / 最新 / 精选）、分类（风景 / 人像 / 街拍 / 静物 / 建筑）、搜索入口、作品流 |
| 图片详情 | 大图、作品名、作者、尺寸与格式、主色、标签、「同空间」入口、收藏 / 下载 |
| 空间 | 空间名、类型（个人 / 团队）、已用容量与图片数、成员、空间内作品 |
| 上传 | 选择空间、选图、上传进度、审核状态（待审核 / 已通过） |
| 我的 | 账号、会员状态、我的空间、我的作品与收藏、退出 |
| 登录 | 微信登录、未绑定时的绑定表单 |

**真实素材**：9 张开放许可照片（Wikimedia Commons，CC0 / CC BY-SA / PD），
`assets/img/` 原图、`assets/img-base64.json` 内嵌版。作品名按照片真实内容命名。

**导出形态**：每方向一个单文件 HTML，展示板上 5 台手机（375×812，微信外壳）＋1 张转发卡片；
每台可点。三版统一尺寸才能横比。

**不可读性红线**：正文 ≥14px、标签 ≥12px，对比度 ≥4.5:1；胶囊区不放可点元素。

## Phase 4 · 六个候选

### A1 · 最佳设计师｜杉本博司（Hiroshi Sugimoto）

- **借的机制**：长曝光把时间压成一张图——照片是页面里唯一的光源，界面自己不发光。
  页面底色近黑（#0A0A0B），照片满幅出血，文字退成银灰（#B6B4AF）；一屏一张，纵向慢节奏。
- **不借的**：他的海景题材、银盐颗粒质感、黑白单色。这次的照片是彩色的，颜色永远来自照片本身。
- **主角素材**：整幅照片。
- **骨架**：一张图占 70% 屏高 + 下方一行美术馆式作品标签（编号 / 标题 / 作者 / 尺寸）。
- **胆量**：整屏没有卡片、没有边框、没有阴影，只有图和一行字。
- **form 来自内容的哪里**：这是一个「看照片」的地方，照片的明暗就是界面的明暗。

### A2 · 最佳设计师｜Irma Boom

- **借的机制**：书是被「编辑」出来的——不是把图堆在一起，而是用跨页节奏、图版编号、
  图注行把图片组织成一册。一屏内 1 张跨栏大图 + 2 张缩进小图 + 一行图注。
- **不借的**：她的荧光专色与超厚书体、无字天书式的实验排版。这次用暖纸白 + 墨黑 + 一点取材自照片的专色。
- **主角素材**：被编排的一组照片。
- **骨架**：编辑网格（不等分三栏），刊头 + 页码 + 图注，每屏像一页书。
- **胆量**：页码、期号、图版号都真的排出来，像一册期刊而不是一个 feed。
- **form 来自内容的哪里**：图片分享平台的本职就是把散落的照片编成一册给人看。

### B1 · 现实参照｜VSCO（App Store 官方截图，`refs/VSCO-Photo-Video-Editor.jpg`）

- **量到的规则**：全黑机身（#0B0B0B 一带），照片满幅；标签是 11px 全大写宽字距（PRESETS / EDITING TOOLS），
  正文小写 15px；控件只用一条 1px 细线与一条滑块，颜色只给「当前值」那一处（黄）。
- **借的机制**：工具退后——底部只留一条极细的控制条与三个动作，其余让给照片。
- **不借的**：它的胶片颗粒、黑白蒙版对比图、黄绿色滑块配色。
- **主角素材**：满幅照片 + 一条细控制条。
- **骨架**：图片全屏，底部一条 44px 的控制栏（收藏 / 下载 / 更多），没有卡片流。
- **form 来自内容的哪里**：这是一个看图工具，工具的手感应该像一台相机而不是一个商场。

### B2 · 现实参照｜Unsplash（`refs/Unsplash.jpg`）

- **借的机制**：分类是图墙（2×3 图块），搜索是一行，底部四个图标 tab；层级靠「图片大小」而不是分隔线。
- **不借的**：白色细字压在照片上的标题位、iOS 系统 tabBar。
- （与 B1 同属深底照片流，外观家族撞车，只留作备选。）

### C1 · 秒数轮盘｜App 风格库 #8 键盘优先命令面板（Raycast 式，样张 `assets/style-specimens/app/08-command-palette.jpg`）

- **借的机制**：一屏只有一条输入行 + 分组建议 + 等宽参数列；结果行的右侧对齐「尺寸 / 色 / 空间」。
- **不借的**：近黑面板、彩色小方块图标、⌘ 键帽。
- **主角素材**：检索行 + 紧凑结果行（含 56px 缩略图）。
- **骨架**：检索台 → 结果列表 → 详情（检索行常驻顶部）。
- **胆量**：把「找一张图」做成这个产品的主界面，而不是把搜索塞进顶栏。
- **form 来自内容的哪里**：图库的核心动作是检索；用户的记忆是「我记得有一张雪山的图」。

### C2 · 秒数轮盘｜东亚风格库 #8 杉浦康平信息曼荼罗（样张 `assets/style-specimens/east/08-sugiura-info-mandala.jpg`）

- **借的机制**：同心环 + 放射刻度把一堆分类压成一个盘。
- **判断**：去掉这个手法，信息更清楚——曼荼罗是万能隐喻，用在图片浏览上属于用力过头。留作备选，不做完整版。

## 选三张做完整版

| 版本 | 候选 | 理由 |
|---|---|---|
| dir-1 | A1 暗房（杉本博司） | 气质最安静、和现有紫漾体系差别最大；一屏一张，图片自己说话 |
| dir-2 | A2 编辑成册（Irma Boom） | 结构最不同：编辑网格 + 图注 + 页码，把「分享」做成「刊物」 |
| dir-3 | C1 检索台（Raycast 机制） | 交互结构最不同：首屏是检索行；用中性浅色重做，避开 Raycast 的黑色面板 |

备选（看中可换成完整版）：B1 工具退后（VSCO）、B2 分类图墙（Unsplash）、C2 信息曼荼罗。
