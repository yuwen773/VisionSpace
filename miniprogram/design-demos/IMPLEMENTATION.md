# 设计稿 → 小程序页面：这次落了什么、没落什么

日期：2026-11-24
设计稿：`final.offline.html`（浅色紫漾 / 深色极光）
代码：`miniprogram/src`，7 个页面全部按这套版式重排

## 版式落地的四件事

1. **页面留白 20px（40rpx）**，双列图片列宽 325rpx，间距 20rpx —— 与定稿一致；`GRID_COLUMN_WIDTH_RPX` 同步从 343 改成 325，图片高度按新列宽重算。
2. **不再用卡片**：图片、列表、表单全部去掉圆角、投影与容器底色，分隔只用 `--vs-rule` 的 1rpx 细线。
3. **两层字级**：正文 28rpx（14px），标签与元信息 24rpx（12px）；数字与编号走 `--vs-font-mono`。
4. **主按钮用墨底纸字**（`--vs-text` / `--vs-bg`），不再用品牌色铺满；强调色只留给当前态、图注编号与链接。

## 设计稿里有、真机没有的（有意不做）

定稿的「本期目录 / 图版号 / 用量刻度 / 作者与年份」是示意数据，真实接口没有这些字段，落地时换成了真实存在的东西：

| 定稿里的 | 真机换成 |
|---|---|
| 刊头「第 04 期 · 2026 冬」 | 右对齐的 `summary`（检索时是「共 N 件作品」） |
| 本期目录（分类 + 图版号 + 张数） | 顶部的分类行（来自 `tagCategory.categoryList`），当前项用强调色 |
| 图版号 014 | 去掉；空间列表用真实的刊行序号 01/02/03（`space/index.ts` 的 `serial`） |
| 空间用量条 12% | 去掉；接口没有容量字段，不编造 |
| 详情页「同空间」缩略图 | 去掉；详情接口只给了 `spaceId`，没有同空间作品 |
| 「收藏 / 下载 / 同空间」动作 | 保留原有的「分享给朋友」按钮 + 网页端提示 |

## 验证方式
