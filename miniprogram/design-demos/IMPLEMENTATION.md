# 设计稿 → 小程序页面：这次落了什么、没落什么

日期：2026-11-24
设计稿：`final.offline.html`（浅色紫漾 / 深色极光）
代码：`miniprogram/src`，七个页面全部按这套版式重排（提交 b1d3084）

## 版式落地的四件事

1. **页面留白 20px（40rpx）**，双列图版间距 20rpx；列宽不再各页写死——`GRID_COLUMN_WIDTH_RPX` 是唯一来源，页面从 `data.columnWidthRpx` 取，同时决定图片高度与 `.grid-item` 的宽度。
2. **不再用卡片**：图片、列表、表单全部去掉圆角、投影与容器底色，分隔只用 `--vs-rule` 的 1rpx 细线。
3. **字级**：正文 28rpx（14px）、标签与元信息 24rpx（12px）、页面标题 34–60rpx；数字与编号走 `--vs-font-mono`。
4. **主按钮用墨底纸字**（`--vs-text` / `--vs-bg`），不再用品牌色铺满；强调色只留给当前态、编号与链接。错误文案用 `--vs-danger`（浅色 `#B42318`，深色 `#FF8A80`）。

## 定稿里有、真机没有的（有意不做）

定稿的「本期目录 / 图版号 / 页码 / 第 N 辑 / 用量刻度」是示意数据，真实接口没有这些字段。落地时换成真实存在的东西，不编造：

| 定稿里的 | 真机换成 |
|---|---|
| 刊头「第 04 期 · 2026 冬」 | 右对齐的 `summary`（检索时是「共 N 件作品」） |
| 本期目录（分类 + 图版号 + 张数） | 顶部分类行（来自 `tagCategory.categoryList`），当前项用强调色 |
| 图版号 014（列表与详情） | 不去造：信息流没有稳定编号。空间列表用真实的刊行顺序 01/02/03（`space/index.ts` 的 `serial`） |
| 页码 014 / 018 | 不做：信息流是无限加载，没有「本期共几页」这个事实 |
| 空间详情「个人空间 · 第 03 辑」 | 只显示接口给的 `typeText` 与件数，不编辑号 |
| 空间用量条 12% | 不做：接口没有容量字段 |
| 详情页「同空间」缩略图 | 不做：详情接口只有 `spaceId`，没有同空间作品 |
| 「收藏 / 下载 / 同空间」动作 | 保留原有的「分享给朋友」+ 网页端提示 |
| 详情页尺寸与格式 | **已落**：`specText` = `1600 × 900 · JPEG`，缺失时退回文件体积；主色做成标题上方的小色块 |

## 没做的功能（不是漏）

- **上传页选择空间**：现流程由「空间详情 → 上传」带 `spaceId` 进入，上传页只做登记；加空间选择器属于新增功能，不在这次视觉改版范围。
- **登录页自动登录态的文案**：品牌区块在所有阶段都会渲染，所以标题只说「登录后浏览个人与团队空间」；「该微信尚未绑定账号」只放在绑定表单那一支。

## 验证方式

- `npx vitest run` 132 项通过；`tsc` 两份配置无错误；WXML 里每个 `bind*` 都能在对应 ts 找到处理函数；所有 WXSS 过 postcss 解析。
